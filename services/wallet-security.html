02 / PROTECT YOUR ACCESS

Build a stronger security baseline

  • Use unique, long passwords and a reputable password manager.
  • Enable multi-factor authentication, preferably with an authenticator app or hardware security key where supported.
  • Secure the email account used for password resets and exchange notifications.
  • Install wallet applications and browser extensions only from verified official sources.
  • Keep operating systems, browsers and security software updated.
  • Review active sessions, connected devices and account recovery options.

Protect wallet recovery information

Keep recovery phrases offline and private. Anyone who obtains a seed phrase or private key may be able to control the associated assets. A legitimate support agent should never ask you to disclose these secrets.

If you suspect compromise

Use a trusted device to secure email and exchange accounts, revoke suspicious sessions where possible, contact the platform through its official channel and preserve relevant alerts and transaction records. If a wallet secret may have been exposed, consult the wallet provider's official safety guidance before taking action.

Important safety note

Never send passwords, private keys, seed phrases, one-time codes or remote-access credentials. No recovery outcome or return of funds is guaranteed.
