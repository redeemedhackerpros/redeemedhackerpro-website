HOW TO PUBLISH
1. Open https://github.com/redeemedhackerpros/redeemedhackerpro-website
2. Create a new branch named website-rebuild-review (recommended).
3. Upload/replace the files from this ZIP in the repository root, keeping the folder structure. Do not upload the outer ZIP itself as a website file.
4. Review the changed files and commit with: Improve homepage and add service pages
5. Check the GitHub Pages deployment and test the homepage, all four service pages, /posts/, /portal.html, /privacy.html and /terms.html.
6. If everything works, merge the review branch into main.
