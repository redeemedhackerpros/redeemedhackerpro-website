# Security Policy

## Reporting a vulnerability

Please report suspected security issues privately to the website operator using the support email published on the official website: support@redeemedhackerpro.com.

Include a clear description of the issue, affected page or component, steps to reproduce it safely, and any relevant screenshots with secrets or personal data removed. Do not include passwords, authentication codes, private keys, wallet seed phrases, or other sensitive information.

Please do not publicly disclose an unpatched issue or access, alter, or download other people's data while testing. Only test systems you own or have explicit permission to assess.

## Scope and response

This repository contains a public static website and its publishing workflow. A report may concern the website, its source code, or the automated publishing process. The operator will review reports as reasonably possible; a response time or remediation outcome is not guaranteed.

## Supported version

The deployed version from the default branch is the version intended for security fixes.
